# Nexo Store

Loja virtual demonstrativa desenvolvida com React. Este é meu segundo projeto com React, criado enquanto estudo desenvolvimento front-end.

## Sobre o projeto

Desenvolvi a Nexo Store para praticar o que venho aprendendo. O projeto inclui catálogo de produtos, páginas de detalhes, carrinho e um fluxo de checkout simulado.

## Funcionalidades

- Catálogo de produtos com imagens, descrições e preços
- Página de detalhes para cada produto
- Carrinho com opção de adicionar e remover produtos
- Controle de quantidade dos itens
- Cálculo do total do pedido
- Formulário de entrega
- Seleção de forma de pagamento para demonstração
- Confirmação visual do pedido
- Layout responsivo para celular e computador

## Tecnologias

- React
- JavaScript
- React Router
- Tailwind CSS
- Lucide React
- Vite

## O que pratiquei

- Componentes reutilizáveis
- Props e comunicação entre componentes
- Estado com `useState`
- Renderização de listas com `map`
- Busca de produtos com `find`
- Cálculo de valores com `reduce`
- Navegação com rotas e parâmetros de URL
- Formulários controlados
- Layout responsivo com Tailwind CSS

## Sobre o checkout

O checkout é uma simulação para demonstração. O projeto não possui back-end, não envia os dados do formulário e não processa pagamentos. Os itens do carrinho ficam no estado da aplicação e são perdidos ao recarregar a página.

## Aprendizado

Este projeto faz parte do meu processo de aprendizado em desenvolvimento front-end. Durante a construção da Nexo Store, pratiquei conceitos de React e continuo aprimorando minhas habilidades.
